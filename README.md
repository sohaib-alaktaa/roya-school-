# Roya School Website 🏫

A clean, responsive showcase website designed and developed for **Roya School**. Built purely with vanilla web technologies, focusing on clean UI design, accessibility, and fast load times without external libraries or frameworks.

---

## 🌐 Live Demo

Visit the deployed website on GitHub Pages:  
👉 **[https://abdulmalek44.github.io/roya-school/](https://abdulmalek44.github.io/roya-school/)**

## 🛠️ Built With

* **HTML5:** Semantic structure and content layout.
* **CSS3:** Responsive layout, flexbox/grid styling, animations, and media queries.
* **JavaScript (ES6):** Client-side interactivity and navigation behavior.
